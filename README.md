# Depth Strike (prototype)

**Play in your browser: https://orbitfoxstudio.github.io/depth-strike/**

A submarine battle game by Orbit Fox Studio. MISSILE shoots up at jets, ships and falling bombs; TORPEDO shoots sideways at enemy subs.
Drag to move, swipe up or down to dive. Works on phones and desktop (arrows to move, Space = missile, X = torpedo).

This repository only holds the published web build.
